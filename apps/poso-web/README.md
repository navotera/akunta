# POSO Web

SvelteKit SPA for POSO, the operational sales and purchasing app.

```bash
cd apps/poso-web
pnpm install
pnpm dev
```

Default local URL: `http://poso.akunta.local:5174`.

Add local hosts when needed:

```text
127.0.0.1 poso.akunta.local ecopa.akunta.local accounting.akunta.local
```

The current screen set is phase 1:

- `/sales`
- `/sales/new`
- `/purchases`
- `/purchases/new`
